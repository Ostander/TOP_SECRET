## Проект: TOP_SECRET v0.2

### 1. О проекте
Исследовательская симуляция, в которой агенты со спайковыми нейросетями самостоятельно развивают интеллект через эволюцию архитектуры, внутрижизненное обучение и гормональную модуляцию.

### 2. Текущая архитектура нейросети
- **Спайковая LIF-сеть** на плоских массивах (V, I, Threshold, Decay, Bias).
- **Разреженные синапсы в CSR-формате** с весами Half (2 байта), до 900 млн синапсов.
- **Сенсоры (100 нейронов)**, моторы (4 нейрона), скрытый резервуар (по умолчанию 1000 нейронов).
- Вход бинаризован (0 — пусто, 1 — объект). Сенсор мгновенно сравнивает вход с порогом (1.0) и генерирует спайк.
- Фоновый шум для спонтанной активности.

### 3. Мир
- Двумерная карта 30×30, стены по краям. Планируется переход в 3D (OpenTK).
- Агент получает сетчатку 10×10 пикселей, где видит себя, стены и других агентов (пока только стены).
- Движение: 4 направления (вверх/вниз/влево/вправо) по моторным спайкам.

### 4. Развитие и эволюция (в разработке)
- **Геном (ДНК)** — набор генов-правил, запускающих рост мозга (добавление нейронов/синапсов) в ответ на внутренние сигналы (время, ошибка предсказания).
- **Структурная пластичность** — методы AddNeuron/AddSynapse расширяют сеть во время жизни.
- **Эволюция** — мутации генома при размножении, отбор по выживаемости.

### 5. Обучение (планируется)
- STDP (пластичность, зависящая от времени спайков).
- Модуляция ошибкой предсказания сенсорного потока (аналог дофаминового подкрепления).
- Внутренняя мотивация (минимизация ошибки предсказания).

### 6. Гормоны и эмоции (планируется)
- Глобальные переменные (дофамин, кортизол, окситоцин) влияют на Decay, Threshold, скорость STDP.
- Уровни гормонов меняются в зависимости от ошибки предсказания, встреч с агентами и т.д.

### 7. Ограничения (RTX 3050 6 ГБ)
- Максимум ~736 000 нейронов и 900 млн синапсов на всю симуляцию.
- Рекомендуемая популяция: 14 агентов по 50 000 нейронов / 50 млн синапсов.

### 8. Файлы проекта
- `src/SpikingNetwork.cs` — ядро спайковой сети.
- `src/Agent.cs` — агент, сенсоры, действие.
- `src/World.cs` — карта и мир.
- `src/Program.cs` — запуск и тестовый цикл.
- `src/Renderer.cs` — заглушка для будущей отрисовки.
- `Genotyp.json` — лимиты для типов нейронов (будущая эволюция).
